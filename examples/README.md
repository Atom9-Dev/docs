# Atom9 Examples

Runnable examples for Atom9 Auth integration.

## Available examples

- [`vanilla-js`](./vanilla-js) — minimal browser integration flow
- [`node-express`](./node-express) — minimal server integration flow

## Quick start

1. Copy `vanilla-js/index.html`
2. Set your tenant/app values
3. Use onboarding endpoints from `https://id.atom9.com`
4. Test magic-link and OIDC starts
